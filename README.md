# 🎵 Music Review

Meu primeiro projeto em Java.

## Funcionalidades

- Cadastro de artistas
- Cadastro de álbuns
- Cadastro de músicas
- Avaliação de artistas
- Avaliação de álbuns
- Avaliação de músicas
- Validação de notas (0 a 10)

## Tecnologias
- Java
- IntelliJ IDEA

## Objetivo
Projeto criado para praticar os conceitos básicos de Java, como:
- Scanner
- if/else
- switch
- while
- Variáveis
